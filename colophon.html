Colophon

How this thing is built.

Short version: hand-written HTML, no framework, no build step, no analytics, no cookies. It is about as small as a website can reasonably be.

The name

The domain is rker.me, which is the back half of my surname. The point of it is the email address: p@rker.me, where the @ does double duty as the a. The home page is built around that one idea — the wordmark is the address, and clicking it copies it.

Type

Space Grotesk for the name and body, Space Mono for labels, navigation and anything that wants to look like metadata. A matched pair, which keeps the personality consistent without needing a third face.

Colour

A warm off-white rather than pure white, a warm near-black rather than pure black, and a single electric indigo used sparingly — mostly on the @. One accent, used rarely, does more work than a palette.

Dark mode follows your system setting automatically via prefers-color-scheme. There is no toggle, because your operating system already has one.

Build

There isn't one. Every page is plain HTML written by hand. No bundler, no framework, no node_modules, nothing to go stale in six months. The whole site is a folder of files.

Hosting

The source lives in a GitHub repository. Cloudflare serves it as static assets and redeploys on every push, so editing a file in the browser is enough to update the live site. Security headers are applied at the edge via a _headers file.

Machine readable

Probably more metadata than a page this size warrants, which was rather the point: schema.org Person data as JSON-LD, Open Graph and Twitter cards with a generated share image, robots.txt, sitemap.xml, a web app manifest, and an llms.txt for language models that look for one.

Accessibility

Semantic markup, a real heading structure, visible keyboard focus, contrast that holds up in both themes, and a live region so the copy-to-clipboard confirmation is announced rather than just seen. Every animation is switched off entirely when prefers-reduced-motion is set.

Privacy

No analytics, no tracking pixels, no cookies, no third-party scripts. I don't know you're here and I'd rather keep it that way. The typefaces are self-hosted too, so no request leaves your browser for those either.
